# Silksong — Pharloom at Dusk

An environment-first Omarchy theme inspired by *Hollow Knight: Silksong*:
ink-blue surfaces, faded teal light, silk-red accents, and brass highlights.

## Backgrounds

The five still backgrounds are empty environment scenes sourced from the
community-maintained Hollow Knight Wiki: Far Fields, Mossy Grove, Whispering
Vaults, Wormways, and Underworks. They intentionally contain no characters or
HUD. `06-mossy-grove-drift.gif` is a small, locally generated ambient zoom from
the character-free Mossy Grove scene so the theme has an animated picker entry.
Omarchy accepts GIF files in the theme background rotation; support for MP4/WebM
depends on the wallpaper backend and is not part of the theme format.

Sources and attribution:

- Environment screenshots: [Hollow Knight Wiki — Silksong pre-release materials](https://hollowknight.wiki/w/Category:X_SS_Pre-Release_Materials), sourced from Team Cherry game material.
- Theme palette and icon treatment: original work for this Omarchy theme.
- The animated GIF is a derivative crop/zoom of the character-free Mossy Grove
  screenshot for personal desktop use.

## Icon ideas

- Weaver needle for the launcher/menu button.
- Bellhart bell for notifications and the clock separator.
- Shellwood leaf or moss tuft for network and audio indicators.
- Cogwork gear for updates and system status.
- Crest/shard motifs for battery and power.
- Silk-thread dividers connecting bar modules.
- A tiny mask glyph for the focused workspace, with numbered inactive slots.

## Notes

This theme is intentionally environment-led and excludes character key art and
gameplay frames with visible characters.
